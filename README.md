# HZ Security System Enterprise

Landing page rasmi: **https://hzsecuritysystem.netlify.app**

(Juga boleh dibuka di https://ayyadzainuddin88.github.io/hz-security-system/)

Pelanggan pilih perkhidmatan (CCTV, Autogate, Alarm, Door Access, Intercom, Barrier Gate, PABX, Networking, Aircond, Electrical, Gate, Home Renovation), pilih **Ada Masalah / Repair** atau **Pemasangan Baru**, dan terus dibawa ke WhatsApp **017-229 1807** dengan mesej yang siap ditulis.

## Kemas kini

- Nombor WhatsApp, pautan Facebook dan TikTok: objek `CONFIG` dalam `index.html` (bahagian `<script>` di bawah).
- Senarai dan penerangan perkhidmatan: senarai `SERVICES` dalam fail yang sama.
- Logo dan gambar: folder `assets/`.

Laman ini dihoskan oleh Netlify (projek `hzsecuritysystem`) dan GitHub Pages. Setiap push ke `main` dikemas kini di kedua-duanya secara automatik.

## Embed dalam Google Sites

Guna `https://hzsecuritysystem.netlify.app/?embed=1`: hanya grid perkhidmatan dan pilihan Repair / Pemasangan Baru dipaparkan, sesuai untuk kotak Embed (tinggi ±700px).
